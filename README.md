# 🎯 EduSync Meeting Management System

![Python](https://img.shields.io/badge/python-v3.13+-blue.svg)
![Django](https://img.shields.io/badge/django-v5.2+-green.svg)

A comprehensive, modern meeting management system built with Django, featuring internal video conferencing, AI-powered transcription, and real-time collaboration tools.

## 🌟 Features

### 🎬 **Internal Video Conferencing**
- WebRTC-based video/audio calls
- Screen sharing capabilities
- Real-time chat during meetings
- Multi-participant support
- Mobile-responsive interface

### 🤖 **AI-Powered Intelligence**
- Automatic meeting transcription
- AI-generated meeting summaries
- Action item extraction
- Speaker identification
- Confidence scoring

### 👥 **Multi-User Dashboards**
- **Admin Dashboard**: System-wide management and analytics
- **Organizer Dashboard**: Meeting creation and participant management
- **Participant Dashboard**: Meeting participation and personal calendar

### 📊 **Meeting Management**
- Schedule and organize meetings
- Send automated invitations
- Manage participants and permissions
- Meeting notes and attachments
- Recurring meeting support

### 🎙️ **Recording & Playback**
- High-quality meeting recordings
- Automatic transcription processing
- Bookmark important moments
- Export transcripts (TXT, PDF, SRT)
- Recording access controls

### 📱 **Modern Interface**
- Responsive design for all devices
- Dark/light theme support
- Intuitive user experience
- Real-time notifications
- Progressive Web App capabilities

## 🛠️ Tech Stack

### **Backend**
- **Django 5.2+** - Web framework
- **Django Channels** - WebSocket support
- **PostgreSQL** - Primary database
- **Redis** - Caching and sessions
- **Celery** - Background tasks

### **Frontend**
- **HTML5/CSS3** - Modern web standards
- **Bootstrap 5** - UI framework
- **JavaScript ES6+** - Interactive features
- **WebRTC** - Video conferencing
- **Chart.js** - Data visualization

### **AI & Machine Learning**
- **OpenAI Whisper** - Speech-to-text
- **OpenAI GPT** - Meeting summaries
- **Natural Language Processing** - Content analysis

### **Infrastructure**
- **Render** - Cloud hosting
- **WhiteNoise** - Static files
- **Gunicorn** - WSGI server
- **GitHub Actions** - CI/CD
